# SCY Chat — запуск на Windows

SCY Chat — небольшой веб-мессенджер с регистрацией, личными сообщениями в реальном времени, профилями, аватарками и отправкой изображений.

## Что нужно
- Windows 10/11
- Node.js LTS (скачать с официального сайта: https://nodejs.org/)
- Интернет при первой установке зависимостей

## Запуск
1. Распакуй `scy-chat-project.zip` в отдельную папку.
2. Установи Node.js LTS, если он ещё не установлен.
3. Открой папку проекта в Проводнике.
4. В адресной строке папки введи `cmd` и нажми Enter.
5. Выполни команды по очереди:

   ```bat
   npm install
   npm start
   ```

6. Открой браузер и перейди на **http://localhost:3000**.
7. Создай аккаунт. Чтобы проверить сообщения, открой сайт в другом браузере/профиле и создай второй аккаунт.

Остановить сервер: в окне командной строки нажми `Ctrl + C`.

## Как проверить с телефона в той же Wi-Fi сети
1. Убедись, что телефон и компьютер подключены к одной сети.
2. На Windows открой CMD и выполни `ipconfig`.
3. Найди IPv4-адрес активного Wi-Fi адаптера, например `192.168.1.25`.
4. На телефоне открой `http://192.168.1.25:3000`.
5. Если страница не открывается, разреши Node.js доступ в частной сети в брандмауэре Windows.

## Что сохраняется
- Пользователи, хеши паролей, сообщения и изображения — в локальной SQLite-базе в папке `data`.
- Сессии — в SQLite-файле в той же папке.
- Не удаляй папку `data`, если хочешь сохранить аккаунты и переписки.

## Ограничения текущей версии
- Это стартовый проект, а не готовая публичная платформа Telegram-масштаба.
- Для доступа через интернет с разных сетей нужен сервер/хостинг, HTTPS и постоянное хранилище.
- Перед публичным запуском обязательно задай постоянный `SESSION_SECRET` в переменных окружения и включи HTTPS.
- Изображения сохраняются прямо в базе данных; для большого проекта лучше подключить объектное хранилище.
- В текущей версии есть личные чаты, но нет групп, голосовых звонков, восстановления пароля и сквозного шифрования.
- Уведомление — короткий синтезированный звук в открытой вкладке. Автовоспроизведение браузером может требовать предварительного взаимодействия пользователя со страницей.

## Переменные окружения
По умолчанию сервер использует порт `3000`. Можно задать `PORT` и `SESSION_SECRET` через переменные окружения. Для production укажи `NODE_ENV=production` и запускай только за HTTPS-прокси, иначе secure-cookie не будет отправляться.
